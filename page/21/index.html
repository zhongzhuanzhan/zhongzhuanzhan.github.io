展开完整站点简介

OriginCoder 是面向开发者和团队的大模型 API 中转平台。一个 API Key 统一接入 GPT、Claude、DeepSeek、Grok、Gemini 等主流大模型，兼容 OpenAI 接口格式，改一行 base URL 即可调用。基于自建资源池保证模型一致性，Claude Code 与 ChatGPT 合计 20+ 条线路，覆盖高性价比、长期稳定与企业专用方案。

【一个 Key，接入所有主流大模型】

不再为每个模型单独注册、单独付费、单独管理密钥。OriginCoder 用一个 API Key 打通 GPT、Claude、DeepSeek、Grok、Gemini，以及 Codex、Claude Code、Cursor、Cline 等编码工具所需的接口。标准 OpenAI 兼容格式，Python、Node、Go 的现有代码改一个 base URL 就能跑，不用重写客户端。

【Claude Code 与 Codex 的中转接入】

Claude Code 和 Codex CLI 直接读环境变量里的 Key。把 ANTHROPIC_BASE_URL 或 OPENAI_BASE_URL 指向 OriginCoder，填上你的 Key，终端里就能用。

我们为 Claude Code 与 ChatGPT 合计维护 20+ 条线路，每条线路独立监测可用性和延迟，某条线路异常时自动切换，避免高峰期集体掉线。

【自建资源池：满血、不降智】

模型被降智、被限速、被偷偷换成小模型，是这类服务最常见的问题。OriginCoder 基于自建资源池调度，保证你调用的是真实满血模型，输出质量和官方一致，不会在高峰期被降级。这是我们把「模型一致性」写成承诺的原因，也是长期用下来最容易被感知到的差别。

【按量付费，成本可控】

没有套餐绑定，用多少算多少，按 token 计费。每一笔调用都有独立用量记录，可以导出对账。小团队试水和个人开发者不必预付大额，团队规模上去之后再谈更低的单价。

【企业采购：对公付款、开票、专属资源池】

面向企业和团队，OriginCoder 支持对公转账收款并开具发票，采购流程可以走完，财务能入账。大用量客户可以洽谈专属资源池，线路独立、带宽独享，不受公共池高峰期影响。

需要走采购流程的团队，可以直接联系我们获取报价单、服务说明与发票信息。

【新用户与社群】

首次注册后可联系客服领取免费额度，先跑通再决定充值。技术交流与新品内测在 QQ 群（619737520），群内不定期放出 token 体验名额。

【常见问题】

大模型 API 中转站怎么选？

看三点：模型是否满血、线路是否稳定、能否开发票。前两点决定你用得顺不顺，第三点决定公司能不能报销。

Claude Code 可以用第三方 API 吗？

可以。Claude Code 支持通过环境变量 ANTHROPIC_BASE_URL 指向兼容 Anthropic 格式的网关，OriginCoder 同时提供 Anthropic 与 OpenAI 两种格式，配置方式见接入文档。

支持对公付款和开发票吗？

支持。企业客户可走对公转账，我们提供发票与采购所需的合同、报价单材料。

模型会不会被降智？

不会。OriginCoder 基于自建资源池，调度的是真实满血模型，不混用降级线路。高峰期也不会把请求转到小模型上。

价格比官方便宜多少？

按 token 计费，具体单价随模型与线路不同，可在模型价格页查看实时价格。大用量可单独洽谈。

有没有免费额度可以试？

有。首次注册后联系客服领取，用来验证接入和效果，确认没问题再充值。
