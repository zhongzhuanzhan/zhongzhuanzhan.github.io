为提升稳定性，平台支持跨模型或跨供应商的自动路由与故障回退，并通过响应头公开回退原因、实际供应商、路由模式与请求编号，方便开发者审计及排错。每个 API Key 可独立设置速率限制，避免单一应用耗尽全部额度。模型能力与实时价格通过 Models API 动态提供，用户可以按照能力、价格和供应来源选择模型，而不必依赖容易过期的静态清单。
